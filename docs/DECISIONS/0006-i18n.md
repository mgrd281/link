# 0006 — Internationalization

**Decision.** next-intl 4 with `[locale]` routing (`/de`, `/en`, `/ar`; German default, `localePrefix: always`).
`dir="rtl"` for Arabic; components use logical properties (`ms/me/ps/pe/start/end`), directional icons mirror
(`rtl:-scale-x-100`), media controls (play) do not. Product UI font: Geist with IBM Plex Sans Arabic as glyph fallback.
A creator page's language/direction follows the **creator's** locale, not the visitor's.
`setRequestLocale`/`requestLocale` are deprecated by next-intl in favor of `next/root-params`, which is still
`experimental.rootParams` in Next 16.4 — we keep the stable API (lint allow-listed) and migrate when it is stable.
